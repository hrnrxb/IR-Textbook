## 📖 دربارهٔ این مخزن

این مخزن شامل **کامل‌ترین و معتبرترین** نسخهٔ جزوهٔ درس **بازیابی اطلاعات (Information Retrieval)** است که توسط تیم **سه‌نفرهٔ ما** تألیف، ویراستاری و طراحی آموزشی شده است.  
محتوا منطبق بر سرفصل‌های دانشگاهی(کتاب IR by MRS) و با رویکردی علمی – آموزشی تهیه گردیده و هم‌اکنون به‌عنوان مرجع درسی مورد استفاده قرار می‌گیرد.

**ویژگی‌های منحصربه‌فرد این اثر:**
- تألیف جمعی با ویرایش علمی و ادبی دقیق  
- طراحی ساختار آموزشی گام‌به‌گام  
- واترمارک دیجیتال، فرادادهٔ کپی‌رایت و امضای دیجیتال  
- انتشار رسمی با مجوز CC BY-NC-ND 4.0  
- شفافیت کامل در مالکیت و انتساب

## 📂 ساختار مخزن

```
/
├── LICENSE                  # متن کامل مجوز CC BY-NC-ND 4.0
├── README.md                # همین سند
├── HASHES.txt               # هش‌های SHA-256 تمام فایل‌ها
├── chapters/                # فصول جداگانه (هر فصل یک PDF مستقل با واترمارک)
│   ├── Chapter_01.pdf
│   ├── Chapter_02.pdf
│   └── ...
└── complete/
    └── Complete_Book.pdf        #نسخهٔ کامل و یکپارچهٔ کتاب

```

هر فصل به‌صورت مستقل آماده شده تا دانشجویان بتوانند بر اساس نیاز خود دانلود کنند. نسخهٔ کامل نیز برای استفادهٔ جامع در دسترس است.
